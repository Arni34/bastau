# BASTAU — Student Project Ecosystem

**Прод:** https://bastauala.vercel.app *(автодеплой при пуше в `main`)*

Интерактивная экосистема студенческих проектов BASTAU.

---

## Быстрый запуск

Запуск клиентской части:

```bash
python3 -m http.server 4173 --directory bastau

```

Открыть `http://localhost:4173` в браузере. Деплой — статик-хостинг (в репозитории настроен `vercel.json`).

## Маршрутизация

Приложение использует Hash-роутинг. Состояния фильтров и поиска синхронизируются с query-параметрами URL.

* `#/` — Главная страница
* `#/projects` — Каталог проектов с фильтрацией (`#/projects?cat=Design&city=Алматы`)
* `#/project/:id` — Детальная страница проекта
* `#/create` — Форма создания проекта
* `#/people` — Поиск участников и специалистов
* `#/events` — Афиша мероприятий
* `#/mentors` — База менторов
* `#/dashboard` — Личный кабинет пользователя
* `#/profile/:username` — Публичный профиль
* `#/auth` — Вход / Регистрация / Восстановление доступа
* `#/admin` — Панель администратора
* `#/about` — О проекте

## 🛠 Архитектура бэкенда

Проект работает на полноценной связке **Next.js + Supabase**:

**Стек:** Next.js + Supabase (PostgreSQL).
**Роли пользователей:** Интегрированы таблицы `users` и `user_statuses` для управления ролями (`admin`, `moderator`, `user`) и статусами деактивации. Настроены RLS-политики безопасности.
**API Эндпоинты:**
* `/api/users` — управление учетными записями пользователей и основной информацией о них.
* `/api/user-statuses` — обработчик для массового получения и обновления ролей пользователей на сайте.
* `/api/projects` — управление проектами, их жизненным циклом и деталями.
* `/api/events` — работа с афишей и мероприятиями.
* `/api/mentors` — управление базой менторов.
* `/api/applications` — обработка заявок на участие в проектах.
* `/api/notifications` — доставка и управление уведомлениями.
**Авто очистка БД:** Реализовано через CronJobs - очищает помеченные на удаление проекты через месяц после отправления их в корзину.
