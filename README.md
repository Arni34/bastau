# BASTAU — Student Project Ecosystem

**Репозиторий:** https://github.com/Arni34/bastau · **Прод:** https://bastau-arni34s-projects.vercel.app (обновляется автоматически при пуше в `main`)

Кликабельный фронтенд-прототип MVP по ТЗ: **IDEA → PROJECT → TEAM → ACTION → RESULT**.
Статический сайт без сборки: HTML + CSS + ES2020 + GSAP (вендорится локально).

## Запуск

```bash
python3 -m http.server 4173 --directory bastau
```

Открыть `http://localhost:4173`. Деплой — любой статик-хостинг (рядом лежит `vercel.json` с кэш-заголовками).

## Демо-вход

На странице `#/auth` есть кнопки быстрого входа:

- **Ала (админ)** — `u1`, видит админ-панель;
- **Айгерим** — `u3`, обычный участник;
- **Сбросить демо-данные** — возврат к исходному сиду.

Полная регистрация (3 шага) тоже работает. Прототип **не хранит пароли**: всё состояние лежит в `localStorage` под ключом `bastau.v1`.

## Дизайн-система

- **Стиль:** ориентир — tilu.kz: плавающая белая «таблетка» шапки (радиус 999, отступ от краёв, мягкая тень), небесный градиент под ней, центрированные первые экраны и заголовки разделов, белые карточки с радиусом 20 px, тенью `0 10px 30px rgba(0,0,0,.05)` и кнопкой во всю ширину внизу. Брендовые цвета работают акцентами, а не заливками.
- **Цвета:** текст `#1A1A1A`, вторичный `#67707A`. Главные кнопки залиты фирменным градиентом с визитки `--fill-grad` (жёлтый `#FFD44A` → голубой логотипа `#52BCF8`), подпись на них — тёмно-синяя `--on-fill: #0C2740`: она держит контраст на обоих концах градиента (10:1 на жёлтом, 7.2:1 на голубом), а белая провалилась бы до 1.5:1 на жёлтом. При наведении градиент мягко уезжает вбок. Ссылки, фокус-кольцо и активные вкладки — затемнённый `--primary: #0B7BD4` (4.7:1 на белом). Фон — сплошной белый, цвет появляется только в кнопках, бейджах, подчёркивании заголовка и искрах логотипа.
- **Шрифт:** Rubik (400/500/600/700) — как на tilu.kz: дружелюбная геометрия, полная кириллица и казахские глифы. Заголовки 600–700, тело 400.
- **Ритм:** шкала 4/8 px (`--sp-1…--sp-9`), радиусы 10–28 px, сетки на `auto-fill`.
- **Одна высота у всех контролов:** `--ctl: 48px` для кнопок, полей и селектов, `--ctl-lg: 56px` для строки поиска и главных кнопок форм. Пара кнопок первого экрана всегда одной ширины (`min-width: 230px`), на телефоне — во всю ширину.
- **Декор только фоном:** в тексте и кнопках никаких эмодзи и значков-искр; крупные полупрозрачные звёзды (как на визитке) живут в фоновом слое `.aurora` за контентом и медленно дышат. На первом экране одна главная кнопка («Найти проект»), вторая тише, третий сценарий — текстовой ссылкой.
- **Фон:** белая база и живой фирменный градиент — небо сверху справа, тёплый жёлтый снизу слева (как на логотипе). Четыре радиальных пятна (`.blob`) медленно дрейфуют и тянутся за курсором; карточки остаются белыми, чтобы контент читался.
- **Только светлая тема:** `color-scheme: light` — интерфейс остаётся светлым и при тёмной теме системы (поля ввода, скроллбары, календарь).

## Анимации (GSAP)

| Что | Как |
|---|---|
| Заставка при первом заходе | логотип + полоса загрузки, уезжает вверх `expo.inOut`, затем запускает вступление первого экрана; один раз за сессию |
| Вход/выход страницы | fade + y, выход короче входа (0.22 s против 0.45 s) |
| Заголовок героя | SplitText: слова выезжают из-под маски, стаггер 40 мс, `expo.out` |
| Заголовки разделов | SplitText: строки из-под маски по скроллу |
| Карточка героя | подъём с наклоном (`rotationX`) и параллакс при скролле |
| Градиентные пятна | бесконечный дрейф, пауза ниже первого экрана |
| Путь IDEA→RESULT | ScrollTrigger scrub: заливка линии и подсветка шагов |
| Карточки | `ScrollTrigger.batch`, подъём с наклоном, стаггер 70 мс, один раз |
| Счётчики | отсчёт с tabular-nums, видимые считаются сразу |
| Модалки и тосты | подъём снизу, `expo.out` |

Всё уважает `prefers-reduced-motion: reduce` — анимации выключаются, контент остаётся на месте. Анимации страницы живут в `gsap.context` и убиваются при переходе, ScrollTrigger'ы помечены `id: 'view'`.

## Доступность

- Контраст основного текста ≥ 4.5:1 (16:1 у основного, 5:1 у вторичного), цвет никогда не единственный носитель смысла (категории и статусы всегда с текстом).
- Все интерактивные элементы ≥ 44×44 px, видимый focus-ring, `aria-label` у иконочных кнопок.
- Формы: видимые лейблы, подсказки, ошибки под полем с `role="alert"`, фокус на первом невалидном поле.
- Skip-link, `aria-current` на активной навигации, перевод фокуса в контент при смене маршрута, Esc закрывает модалку.

## Следующий шаг к проду

`data.js` — единственный источник данных; при переходе на бэкенд он заменяется на API-клиент, а функции хранилища в начале `app.js` (`load` / `save`) — на запросы. Рекомендуемый стек под пункт 22 ТЗ: Next.js + Supabase (Postgres, Auth, Storage для аватаров, Realtime для уведомлений) — закрывает backend, БД, авторизацию, API, хранение изображений и RLS-политики без переписывания интерфейса.
